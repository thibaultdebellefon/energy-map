# Lessons

Format: [date] | what went wrong | rule to avoid it

- 2026-07-17 | Comtrade/EIA annual data lags ~1 year; requesting the current year (2026) returns empty sets | Always keep fetchers year-parametric and detect empty results, suggesting the latest complete year as fallback instead of failing silently.
- 2026-07-17 | Comtrade returns one row per (mode-of-transport × customs-procedure) per pair; a naive UNIQUE key collapses them arbitrarily and understates values | Filter API calls to motCode=0 & customsCode=C00 (the aggregate total) to get exactly one row per bilateral pair.
- 2026-07-17 | Major oil exporters (SAU, RUS, IRN, IRQ, KWT, LBY, OMN, VEN, ARE) do NOT report bilateral exports to Comtrade — direct export data misses them entirely | For any trade-flow map, augment direct exports (flow=X) with MIRROR data (flow=M, partner imports) to reconstruct these flows. Verified: mirror captures all 9 missing states with correct bilateral breakdowns.
- 2026-07-17 | SVG choropleth fills set via .attr("fill", ...) rendered as the default land colour — a CSS stylesheet rule (.country { fill: ... }) beats a presentation attribute | Set data-driven SVG fills with .style("fill", ...) (inline style wins over stylesheet), and return null to fall back to the CSS default.
- 2026-07-17 | D3 leaderboard bound by key (.data(rows, r=>r.iso)) kept stale DOM order after re-sorting on a filter change | Call .order() on the merged selection to reorder the DOM to match the new data order.
- 2026-07-18 | USGS MCS "World Production" is one CSV (MCS2025_World_Data.csv on ScienceBase) with COMMODITY/COUNTRY/TYPE/UNIT_MEAS/PROD_2023/PROD_EST_2024; commodity names differ (aluminium ore = "Bauxite", curly apostrophes, "Other Countries"/"World total" aggregates) and values include "W"=withheld | Filter TYPE to "Mine production", map country NAMES→ISO3, skip aggregates, treat non-numeric as missing. ScienceBase file list via /catalog/item/<id>?format=json (curl, not WebFetch — WebFetch 403s).
- 2026-07-18 | Pasted HS-code table arrived corrupted (Lithium/Nickel rows merged) | Never guess HS codes: run a Comtrade includeDesc=true test call per code and confirm the returned cmdDesc matches the expected metal before bulk fetching.
- 2026-07-27 | Alpha Vantage NATURAL_GAS is US Henry Hub (~$2.8/MMBtu), a different market from FRED's Asia LNG landed price (~$17). Blindly "preferring the higher-frequency source" silently swapped the product behind a "LNG (Asia)" label | When merging two price sources, only prefer one over the other where they track the SAME instrument. Keep an explicit per-commodity allowlist (AV_PREFER) instead of a blanket rule; cross-check overlapping values before switching.
- 2026-07-27 | Landing hero had ~500px of dead space: `.hero > *` and `.hero-orb` have equal CSS specificity (both single-class, 0-1-0), so the later `.hero > *{position:relative}` overrode the orb's `position:absolute`, dropping it into normal flow at 460px tall | When an absolutely-positioned decorative child lives inside a container that also has a `.parent > *` rule, exclude it with `:not(.orb)` or raise its specificity. Verify with getComputedStyle(...).position, not just the source CSS.
- 2026-07-29 | Stooq's keyless CSV endpoint is now gated behind a JavaScript proof-of-work challenge ("This site requires JavaScript to verify your browser") — plain curl gets an HTML block page, not CSV | For free stock/FX quotes use Yahoo Finance's public chart endpoint `query1.finance.yahoo.com/v8/finance/chart/<symbol>` (keyless, one request per symbol, covers LSE/Tadawul/HKEX/ASX/NYSE, returns regularMarketPrice + chartPreviousClose + currency). FX via the `<CUR>USD=X` pairs. Always live-verify a "free API" before designing around it.
- 2026-07-29 | Wikidata's API rate-limits bursts of rapid wbsearchentities/wbgetentities calls — a 25-item loop returned only 4 logos, and re-runs timed out at the 2-min foreground cap before json.dump ran, losing all progress | For batch external fetches: run in the background (run_in_background) OR write incrementally so a timeout doesn't discard results. When a foreground batch keeps timing out, capture confirmed values from the logs and write them directly rather than re-fetching. Don't trust hardcoded Wikidata QIDs (Q1755034 mapped to "OMV Petrom", not QatarEnergy) — search by name and read P154, guarding for missing `claims`.
